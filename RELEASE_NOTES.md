# Asterix 0.1.4 — ROM-free candidate

Copy Cores, Platforms and Assets to the Pocket SD root. Build/verify your own
complete MAME asterix World EAD ZIP using the supplied scripts, then copy
asterix.rom to Assets/asterix/mmmax4.asterix/. Preserve an existing asterix.sav.
No game ROM, factory EEPROM dump or save is bundled.

The FPGA circuit is identical to the qualified/tested private v014. The user
confirmed its corrected KONAMI animation on Pocket; improved v013 speech is
retained, with possible mild remaining saturation. Validation uses targeted
v014 renderer tests and historical v013 integration, not a new full v014 replay.
The public plain banner replaces the excluded catalog artwork.

EEPROM settings are saved; high scores/save states are not. Full game completion
and every Dock action are not claimed. See README, docs/VALIDATION.md and LICENSING.md.
Preparation does not upload anything; publication requires the lead's final review.
